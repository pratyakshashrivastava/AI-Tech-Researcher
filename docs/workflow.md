# Workflow

## 1. Search

**Step:** Find relevant and reliable external sources.

- Search only when current or external information is needed.
- Prefer official documentation, research papers, universities, government sources, and established technical organizations.
- Avoid unreliable or unsupported sources.
- If search fails, continue using existing knowledge when the question does not require current information.

---

## 2. Analyse

**Step:** Analyze and organize the findings.

- Review the retrieved information for relevance and reliability.
- Identify the key concepts and important findings.
- Compare information from multiple reliable sources when necessary.
- Identify uncertainty, limitations, or conflicting evidence.
- Separate current information from general technical knowledge.

---

## 3. Summarize

**Step:** Generate a clear and structured answer.

- Present the findings in clean Markdown.
- Use proper headings and bullet points.
- Include relevant sections such as key concepts, recent developments, applications, advantages, limitations, and useful resources.
- Mention sources when external information was used.
- Clearly state when current external information could not be verified.
- Always finish with a clearly labelled **Summary** section.
- Complete every section before ending the response.
